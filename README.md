## 作业要求回顾

按任务安排，每人提交两份材料并进行 3–5 分钟口头交流：

1. **一份 Excel**：使用配套模板填写「平台功能地图」和「优先功能建议」。
2. **一张流程图**：自行绘制，提交 PNG 或 PDF，文件名写上姓名和流程名称。
3. **一次口头交流**：讲清一项有依据的发现、一个关键流程判断，以及为什么把某项功能排在第一位。

## 核心结论

- **平台分三块**：学生端（成长与求职）、高校管理端（分析与培养）、数据支撑（岗位 / 技能标签 / 课程培养方案 / 学生经历）。
- **关键流程判断**：能力画像应作为贯通全流程的中枢，测评后持续更新，并被简历、匹配、指导、面试反馈复用，形成闭环。
- **优先功能排序**：① 简历管理与岗位匹配；② 就业市场分析与课程岗位能力对照；③ 语音模拟面试。第一项因高频刚需、数据易获得、且是其他功能的地基而排首位。
